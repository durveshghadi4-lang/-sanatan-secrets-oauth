Sanatan Secrets

Sanatan Secrets is an educational YouTube channel focused on Sanatan Dharma, Ancient India, Indian knowledge, mythology, mysteries, and related educational content.

YouTube APIs

This application uses the YouTube Data API v3 and YouTube Analytics API to access authorized YouTube channel data for analytics and channel-performance analysis.

Privacy

We use authorized YouTube data only for the purposes described above. We do not sell or publicly disclose personal YouTube account data.
